PROJET PERSONNEL

L'objectif de ce projet était de développer une sorte d'arène où combattent différents types de cercles.

Prérequis pour pouvoir lancer le projet :
-JDK 25
-Maven

Pour lancer le projet, il faut cloner le repo, se placer dans le dossier du projet et lancer le jeu avec Maven (mvn javafx:run)

Pour le moment, le projet est séparé en ces parties suivantes :
-Entity : gère tout ce qui est entité
-Hitbox : gère tout ce qui est hitbox
-Main : boucle principale du jeu
-Dossier types : recense tous les types de cercles qui peuvent combattre (pour le moment il n'y en a qu'un)

Ce projet m'a permis de découvrir JavaFX et d'approfondir mes connaissances en Java déjà vues en cours, tout en faisant un projet rigolo.

EN : PROJECT CODED BY VAUCHEL ANTHONY

PERSONAL PROJECT

The goal of this project was to develop a kind of arena where different types of circles fight against each other.

Requirements to run the project:
-JDK 25
-Maven

To run the project, clone the repository, navigate to the project directory, and launch the game using Maven (mvn javafx:run)

For now, the project is divided into the following parts:
-Entity: handles all entities
-Hitbox: handles all hitboxes
-Main: contains the main game loop
-Types folder: contains all the different types of circles that can fight (there is currently only one)

This project allowed me to discover JavaFX and deepen my existing Java knowledge from my coursework, while also working on a silly personnal project.
